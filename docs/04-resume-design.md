# 04 — lizheng.dev 简历设计

状态：新设计规格，尚未实现。内容来源：[英文简历](content/01-resume-en.md)、[中文简历](content/02-resume-zh.md)。不沿用旧模板、旧 CSS 或旧装饰系统。

## 视觉方向：一份认真排印的个人履历

优先级依次为正文阅读、信息定位、可信度与个性。页面像一份经过专业编辑的长篇履历：清晰的姓名抬头、节制的照片、稳定的章节层级、紧凑但可读的经历条目。布局偏保守，不使用掌机皮肤、卡片墙、夸张滚动特效或装饰性大面积留白。

## 信息结构

1. 顶部工具区：站点标识、语言切换、主题切换、打印。
2. 身份抬头：姓名、职位、头像、两行 tagline、真实社交链接。
3. 职业概述及副标题。
4. 工作经历：公司、职位、地点/时间、完整成果条目。
5. 教育背景、专利、领导力与沟通、工作之外。
6. 页脚：本地化版权；低干扰的 Markdown 版本链接。

桌面可在正文旁放置窄幅章节目录。目录只作辅助，正文保持一条连续的阅读列；不把正文拆成需要点击切换的标签页。各章节使用稳定 id，方便深链接、目录导航和 agent 引用。

## 排版规格

| 角色 | 设计 |
| --- | --- |
| 页面容器 | 最大约 1120px，左右留白随视口变化 |
| 正文 | 英文约 65–72ch；中文约 32–38 个汉字宽 |
| 身份标题 | Newsreader 可变衬线，48–64px；中文 Noto Serif SC，40–52px |
| 英文正文 | Source Sans 3，17–18px，行高 1.65–1.75 |
| 中文正文 | Noto Sans SC，17–18px，行高 1.8–1.9 |
| 章节标题 | 衬线，24–30px；字重和间距形成层级 |
| 日期与辅助信息 | Geist Mono / 中文 sans，13–14px |
| 头像 | 新裁切的真实照片，约 88–112px；不承担首屏全部视觉重心 |

这些字体为拟选方案；实施时检查字体许可证、中文覆盖和字体文件预算。字体本地托管并按语言加载，正文不用像素字体。中文断行遵循标点禁则；日期和英文职位在小屏正常换行，不用缩小字体解决溢出。

## 色彩与主题

| 语义 | Light 方向 | Dark 方向 |
| --- | --- | --- |
| 背景 | 温润白纸，接近 #faf9f6 | 暖调深灰，接近 #17191c |
| 正文 | 深墨灰 | 柔和近白 |
| 次级信息 | 保持可读的中灰 | 保持可读的浅灰 |
| 强调 | 低饱和深蓝绿 | 提亮的蓝绿色 |
| 分隔 | 细线、充足间距 | 低对比细线、同样的信息层级 |

最终颜色通过对比度测量定稿。普通文本至少 4.5:1，大字与交互边界至少 3:1；不能以降低正文对比营造“高级灰”。主题切换同时调整照片周围、链接、焦点、打印规则与原生控件，不仅反转背景色。

## 响应式与阅读细节

- ≥1200px：窄章节目录 + 阅读列；目录 sticky，正文流动。
- 768–1199px：单列正文，目录折叠为轻量章节导航；正文宽度仍受约束。
- 320–767px：约 20px 边距，身份自然折行，经历日期移至公司/职位下一行，控件点击区域至少 44px。
- 200% 缩放和 320px 宽不产生页面横向滚动；长 URL 可断行。
- 导航锚点预留顶部工具区空间。正文不使用 scroll reveal 隐藏内容，直接可读。
- 复制粘贴顺序与视觉顺序一致；外链有可辨识的文本，不把整段经历变成点击区域。

## 四模式与状态

英文/中文分别使用 /en/、/zh/，主题保存在当前 origin。显式选择优先于系统偏好；未显式选择时响应系统变化。存储不可用仍能切换，不抛异常。

初始主题在首帧绘制前确定，避免白闪。两种语言的按钮名称、aria-pressed、当前语言和打印提示完整本地化。切换语言保留当前主题；若对应章节存在则保留章节锚点。跨域不假设共享 localStorage。

## 动效

仅给抬头和工具区提供一次 180–260ms 的淡入，位移不超过 6px。主题颜色过渡约 160ms，按钮反馈约 100ms。正文、锚点目标、打印内容始终可见；无全页转场遮罩。

prefers-reduced-motion 下去除位移和滚动动画，可保留短淡入或直接显示，视觉排版不变。打印时完全移除动画。

## 打印

使用真实打印样式支持 A4 / Letter：保留姓名、职位、必要社交链接和全部正文；隐藏工具、目录、装饰及交互提示。禁止像旧页面一样把身份抬头一并隐藏。页面使用白底黑字，建议 10.5–11pt 正文。

保持章节标题与首段一起，避免公司名与职位分离；不对整段长工作经历强制 break-inside: avoid 导致大片空白。允许多页，自然分页，不为了“一页简历”删掉任何信息。

## 先设计的验收

- DEV-CONTENT：六章节、3 段经历、13 条经历描述、2 教育记录、1 专利、全部原文及外链。
- DEV-MODES：en/zh × light/dark，刷新、存储拒绝、系统偏好、切换状态和可访问名称。
- DEV-READ：桌面/小屏/200% 缩放/长文本/中文断行，无截断和横向滚动。
- DEV-PRINT：A4 与 Letter 输出都保留姓名与全文，合理分页。
- DEV-NOJS：禁用 JS 时全文、外链、语言跳转仍可用。
- DEV-VISUAL：四模式的桌面和移动截图、字体加载前后布局、首帧主题逐项视觉评审。

这些是未来测试和人工评审的目标，不能把截图差异阈值或 Lighthouse 分数等同于排版质量。
