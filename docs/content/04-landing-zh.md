## 关于我

本页是李征的个人入口：六个可交互的设备界面把游戏、通信、计算机、音乐、骑行和摩托等日常兴趣做成可点的场景。李征是微软 Teams 首席软件工程经理，同济大学计算机软件与理论工学硕士、计算机科学与技术工学学士，自 2012 年起在微软从事产品研发；此前在阿里巴巴用户体验部开发内部与开源工具，并在微软亚洲研究院参与数据可视化研究。职业履历、专利与 AI 原生研发实践见 lizheng.dev，长期写作与系统设计思考见 lizheng.blog，个人开源项目见 hexly.ai 与 basaltui.com，中文播客在 his.fm。设备屏幕菜单可打开 GitHub 与 LinkedIn，也可从这里进入上述站点。
