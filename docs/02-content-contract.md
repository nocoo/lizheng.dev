## Markdown 数据边界

四份公开文档是唯一发布 allowlist。身份、标题、描述、版权等放在 frontmatter；正文保持普通 Markdown。新编译器将其转换成受校验的 Content Model；不再把旧 JS 数据作为另一份可编辑来源。

公开输出包括页面 HTML、对应语言的 Markdown、Person / ProfilePage 结构化数据和 sitemap。它们从同一 Content Model 生成。内部来源证据、测试计划、版本核对、README、界面迁移清单和整个 archive 不得进入发布目录。

将内容完整性测试写在新加载器之前：缺失章节、空链接、错误域名、缺失语言、未经允许的文件进入内容清单都应失败。测试验证公开契约，不固定旧 DOM、CSS 类名或模板引擎行为。
